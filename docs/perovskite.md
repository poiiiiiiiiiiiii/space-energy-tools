# 钙钛矿模组回收

站点维护与网页适配：[@poiiiiiiiiiiiii](https://github.com/poiiiiiiiiiiiii) · [打开 `perovskite.html`](https://poiiiiiiiiiiiii.github.io/space-energy-tools/perovskite.html)

## 功能

比较新制模组和脉冲氙灯回收方案。可修改材料回收率、脉冲能量、频率、处理时间、电价、灯寿命及模组发电参数，查看回收收益、工艺成本、平准化度电成本（LCOE）和生命周期评估（LCA）雷达图。

## 算法依据

各材料的原价乘以回收率后加总，得到回收价值。脉冲能量乘总脉冲数换算为电耗，叠加灯耗得到工艺费用。LCOE 用每瓦成本与简化运维费除以寿命期折现发电量。LCA 指标由预设基准按价值加权回收率与工艺电耗修正。

## 适用范围

适合参数敏感性和工艺方案比较。成本、折现和环境指标沿用页面假设，不是实际报价，也不替代有完整清单和边界的生命周期评价。
