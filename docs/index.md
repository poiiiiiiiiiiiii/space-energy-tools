# 激光能量传输系统

站点维护与网页适配：[@poiiiiiiiiiiiii](https://github.com/poiiiiiiiiiiiii) · [打开 `index.html`](https://poiiiiiiiiiiiii.github.io/space-energy-tools/)

## 功能

站点首页集中进入光伏、TCT、轨道和 JA 等工具。可输入各级转换效率、传播距离、发射口径和接收直径，查看全电路效率、光斑与接收面示意图。光电效率子窗口的 PCE 可回填首页。

## 算法依据

把电源转换、电光转换、跟踪损失、光路传输和光电转换按链路相乘。页面用光束参数积、发射口径和距离估算光斑半径 `r = BPP × L / D`，再用 `πr²` 计算面积。按同心、均匀光斑假设，接收面小于光斑时，实际效率乘以接收面积与光斑面积之比；覆盖全部光斑时不再扣减。

## 适用范围

用于链路初估。面积比不考虑偏心、非均匀光强或湍流；要比较实际截获分布，应使用 [TCT 激光版](tctdemo_laser.md)。两页各用自身的口径约定，不宜直接混用半径公式。
