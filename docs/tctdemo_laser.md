# TCT 激光光斑优化

站点维护与网页适配：[@poiiiiiiiiiiiii](https://github.com/poiiiiiiiiiiiii) · [打开 `tctdemo_laser.html`](https://poiiiiiiiiiiiii.github.io/space-energy-tools/tctdemo_laser.html)

## 功能

显示到靶光斑、电池阵列边界、单片接收分布和 TCT 重组结果。支持独立设定电池长宽或自动匹配，以及微、中、强湍流预设。时序图并列显示接收光功率、原始输出电功率和优化后输出电功率，支持悬停和暂停回溯。

## 算法依据

用光束参数积、发射口径与传播距离估算光斑半径 `r = BPP × L / (D/2)`。名义光强用圆形超高斯 `exp[-2(ρ/r)⁸]` 建模；开启湍流后，以 Rytov 方差和衍射尺度调节随机漂移、扩缩、闪烁与纹理。先将完整光场归一到出射功率，再按栅格与每片电池的重叠面积积分。阵列接收功率是这些积分之和，阵列外光功率不计入电输出。

电学部分用单片近似 I–V 曲线与串联限流 MPPT，对比固定接线和 TCT2026 重组。激光版没有旁路二极管模型。每帧正负功率增量均计入累计差值。

## 适用范围

湍流是逐帧随机的工程近似，不是相位屏波动光学求解；曲线用于对比截获和重组效果，不代表实测大气链路或实际电池效率。累计差值不是能量。
