# 轨道温度模拟

站点维护与网页适配：[@poiiiiiiiiiiiii](https://github.com/poiiiiiiiiiiiii) · [打开 `tmp.html`](https://poiiiiiiiiiiiii.github.io/space-energy-tools/tmp.html)

## 功能

选取预设轨道、模拟圈数和初始温度，并分别设置晶硅、钙钛矿电池的吸收率、发射率、转换效率和面热容。对比两条温度曲线及地影区间，查看辐照时序和温度范围，支持导出温度数据 CSV。

## 算法依据

按预设周期和日照比例在恒定太阳辐照与地影零辐照之间切换。沿用原模型 `G × 吸收率 × (1 − 转换效率)` 的热输入口径，净辐射散热按斯特藩–玻尔兹曼关系 `εσ(T⁴ − T环境⁴)` 计算，环境温度设为 2.7 K。程序用四阶 Runge–Kutta 积分，内部步长不超过 5 秒，日照切换处截断步长；每分钟记录一次，并在第 0 分钟记录设定的初始温度。

## 适用范围

这是集总热平衡示意，不由真实轨道根数求地影，也未建模实际热结构、地球红外或反照光。AM0 图只显示无量纲的光谱形状示意，不是标准光谱数据，不驱动温度计算。
